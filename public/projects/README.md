# Project screenshots

Drop screenshots for each project in its folder here. The site picks them up automatically.

- Files must be named `1.png`, `2.png`, `3.png` (PNG or JPG both work; keep the `.png` name or edit the paths in `src/data/content.ts`).
- Any missing file is skipped, so you can add them one at a time.
- If a project has no screenshots yet, its detail view shows "Screenshots coming soon".
- Recommended: landscape shots, roughly 1600x1000, showing the main screen first.

Folders: mattecoach, roadmap, personligt-schema, solkatten, korkortsquiz, tidigare-portfolj
